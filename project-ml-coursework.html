Machine Learning for Data Science

View on GitHub → Course Notes (PDF) →

Overview

Eight machine learning projects from Machine Learning for Data Science, a graduate course at USC. Each is a standalone notebook with its own data, covering preparation, model selection, and evaluation on a public dataset.

Projects

# Project Description Notebook
1 KNN and Distance Metrics Classifies patients as normal or abnormal from six spinal measurements and tests how the distance metric changes the result; test error runs from 0.06 to 0.17 across five metrics. Open →
2 Linear Regression on Power Plant Output Predicts a power plant's hourly electrical output from four ambient measurements, working through outliers, nonlinearity, and interactions; KNN beats the OLS baseline 14.29 to 21.24 on test MSE. Open →
3 Time Series Activity Classification Identifies which of seven activities a person is performing from six wireless sensor channels using time-domain features; the bending detector separates held-out data exactly and the seven-class model reaches 0.842. Open →
4 Regularization and Decision Trees Prunes a clinical decision tree down to readable IF-THEN rules, then compares ridge, LASSO, principal components, and boosting on a 122-predictor crime regression; ridge takes the lowest test MSE. Open →
5 Imbalanced Classification with SMOTE Detects air pressure system failures in Scania trucks where failures are 1.67 percent of the training set; class weighting cuts missed failures from 121 to 35. Open →
6 Multi-Label SVM and K-Means Clustering Assigns family, genus, and species to recorded frog calls from 22 MFCC features; a Gaussian-kernel SVM gets all three labels right on 98.75 percent of test calls. Open →
7 Semi-Supervised and Active Learning Compares a supervised SVM against self-training, k-means, and spectral clustering over 30 fixed splits, then tests whether choosing which points to label beats labeling at random. Open →
8 Transfer Learning for Fungi Image Classification Sorts 9,114 microscopy images of fungal infections into five classes with five frozen ImageNet backbones; ResNet101 leads at 0.8476 test accuracy. Open →

Notes

A complete written treatment of the course, from linear regression and classification through model selection, tree-based methods, and support vector machines to unsupervised learning, semi-supervised and active learning, and neural networks. Each topic is built up from its definitions and formulas to the reasoning behind the method, with worked figures and proofs where they earn their place. Written to stand on its own as a reference; chapter links open the PDF at that chapter.

Ch Chapter Topics
1 Intro and Linear Regression Learning paradigms, bias-variance trade-off, nearest neighbors, OLS, inference, multicollinearity, interactions
2 Classification Logistic regression, Bayes' rule, LDA and QDA, naive Bayes, error measures, class imbalance
3 Linear Model Selection and Regularization Subset selection, cross-validation, ridge, lasso, elastic net, PCR, partial least squares
4 Tree-Based Methods Regression and classification trees, pruning, bagging, random forests, boosting, AdaBoost, stacking
5 Support Vector Machines Maximal margin, soft margin, kernels, multi-class and multi-label SVMs, hinge loss, VC dimension, SVR
6 Unsupervised Learning K-means and k-medoids, hierarchical clustering, choosing K, silhouette and gap statistic, PCA and the SVD, Fisher's LDA
7 Semi-Supervised and Active Learning Self-training, co-training, semi-supervised SVM, cluster and label, uncertainty sampling, query by committee
8 Neural Networks and Deep Learning Perceptron, MLPs and backpropagation, regularization and dropout, CNNs, transfer learning, RNNs, LSTM and GRU
