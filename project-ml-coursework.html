Machine Learning for Data Science

View on GitHub → Course Notes (PDF) →

Overview

Everything from Machine Learning for Data Science, a graduate course at USC, in one place: eight projects and a full set of course notes. The projects run from k-nearest neighbours and regression through trees, SVMs, and clustering to semi-supervised learning and deep transfer learning; each is a standalone notebook with its own data, built around preparation, model selection, and honest evaluation. The table below links every notebook on GitHub, and the chapter guide at the bottom opens the notes PDF at any chapter.

Projects

# Project Description Notebook
1 KNN and Distance Metrics Diagnoses spinal abnormality from six biomechanical measurements with k-nearest neighbours, testing Euclidean, Manhattan, Minkowski, Chebyshev, and Mahalanobis metrics plus distance-weighted voting; the choice of metric alone moves test error from 0.06 to 0.17. Open
2 Linear Regression on Power Plant Output Predicts a power plant's hourly electrical output from ambient conditions, building from simple OLS through interaction and polynomial terms to a tuned KNN regressor; the final model cuts test MSE from 21.24 to 14.29. Open
3 Time Series Activity Classification Recognizes which of seven physical activities a person is doing from raw wireless sensor streams, engineering time-domain features for logistic regression with recursive feature elimination, L1 penalties, and naive Bayes; seven-class accuracy reaches 0.842 and the bending detector is exact on the test set. Open
4 Regularization and Decision Trees Turns a pruned decision tree into readable IF-THEN rules on a clinical dataset, then attacks a 122-predictor crime regression with ridge, LASSO, principal component regression, and XGBoost; ridge wins at 0.01732 test MSE. Open
5 Imbalanced Classification with SMOTE Catches failing air pressure systems in Scania trucks where only 1.67 percent of the training set are failures, weighing class weights against SMOTE oversampling in random forests and XGBoost; missed failures drop from 121 to 35. Open
6 Multi-Label SVM and K-Means Clustering Labels frog calls with family, genus, and species at once from 22 audio features, using one-vs-all Gaussian-kernel SVMs, L1-penalized linear SVMs, and k-means with silhouette selection; 98.75 percent of test calls get all three labels right. Open
7 Semi-Supervised and Active Learning Asks how far you can get with few labels: a supervised SVM against self-training, k-means, and spectral clustering over 30 fixed splits, plus margin-based active learning against random labeling; supervision holds a clear edge at 0.9708. Open
8 Transfer Learning for Fungi Image Classification Classifies 9,114 microscopy images of fungal infections by training heads on five frozen ImageNet backbones: ResNet50, ResNet101, EfficientNetB0, VGG16, and DenseNet201; ResNet101 leads at 0.8476 test accuracy. Open

Notes

I wrote these notes chapter by chapter through the course and assembled them into one book. They start at linear regression and end at deep learning, and every method along the way gets its definitions, the formulas, a figure where one helps, and a plain explanation of why it works. Use the guide below: each chapter opens the PDF right at that chapter.
